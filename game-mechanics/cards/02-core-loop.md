# Core loop

The short cycle of actions the player repeats all game.

**Shows it:** *Universal Paperclips* (make, sell, invest)

**Try it in two minutes:** Name the three things you do over and over in a game you know. Swap one and say what changes.

**Build it:** Ask Claude Code for a one-page loop with three buttons on `/launch`; play it for two minutes, then change one step.
