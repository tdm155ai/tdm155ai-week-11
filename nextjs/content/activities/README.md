Five things we'll do in class today, in order. Each fits on one sheet: add `/print` to the front of the address (for example `/print/activities/01`), or print them all at once from [/print/activities](/print/activities).

1. [Activity 1: Try a game engine](/activities/01). Unity, on the computer set up for it.
2. [Activity 2: Unpack a game you love](/activities/02). Claude maps the mechanics; you talk them over with a partner.
3. [Activity 3: Remix Wordle](/activities/03). Or another daily word game, in your own way.
4. [Activity 4: Motivate the device](/activities/04). A game, or one mechanic, that needs our NFC cards.
5. [Activity 5: Take one thread](/activities/05). One element of games, put to work in a presentation, a pitch, or academic work.
