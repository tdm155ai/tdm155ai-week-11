A game engine is the software big games are built in and run on. Before you start, read [What is a game engine?](/games/what-is-a-game-engine)

**You need:** the computer in the room with Unity open, and a partner.

## Do

1. **Look before you touch.** Find the scene (the world you are building), the list of objects in it, the panel that shows one object's settings, and the Play button.
2. **Find the engine's jobs.** The engine page lists what an engine does for you: rendering, physics, input, audio, an editor, scripting, building for platforms. Which of them can you see on the screen?
3. **Press Play.** Notice what changes when the scene runs, and what you can do in it.
4. **Change one thing.** Move an object, change a light, change a setting, and press Play again.
5. **Ask what it's for.** What kind of game is this tool made for? What would it be hard to make in it?

## Bring back

- One thing the engine made easy.
- One thing you would rather make without an engine, in a web page with Claude, like the [games in this repo](/games).
